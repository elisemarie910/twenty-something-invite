# Twenty Something

An interactive, collage-inspired invitation for Elise & Tamia's joint 22nd and 25th birthday celebration.

## Project

A lightweight, responsive microsite built with **HTML, CSS, and vanilla JavaScript**, hosted with GitHub Pages.

- Minimal editorial cover
- Colorful chrome-and-blue birthday collage
- Event details and dress code
- Responsive mobile styling
- Interactive RSVP **demo** (currently does not save or submit responses)
- Reduced-motion support

## Preview locally

Open `index.html` in a browser. No build tools required.

## Deployment

In the repository, navigate to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

Expected Pages URL after deployment:

https://elisemarie910.github.io/twenty-something-invite/
